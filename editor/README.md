# dsh-card-editor

DSH 模型卡片的**视觉编辑器** —— 拖拽搭建 provider 卡片，导出 JSON 供落成 React 组件。

---

## 用法

```powershell
cd D:\dsh-card-editor
node scripts/serve.mjs
```

打开 <http://127.0.0.1:8899/>

> ⚠ 请用 `node scripts/serve.mjs` 启动，**不要双击 `build/builder.html`**。
> `file://` 下剪贴板 API 受限，且浏览器自动化工具无法操作 `file://` 页面。

## 编辑器怎么用

### 左侧组件栏

| 分组 | 组件 | 说明 |
|---|---|---|
| 容器 | 横排 / 竖排 | 可嵌套；**尺寸随内容增长**（空时 112px） |
| Tab | 下划线 Tab | 拖进来会**自动创建配套面板** |
| Tab | Tab 内容面板 | 与 Tab 用「绑定名」关联 |
| Tab | 分段切换 | 胶囊式切换 |
| 文本 | 字段标题 / 说明 / 区块标题 / 键值行 | |
| 其它 | 开关 / 输入框 / 列表行 / 状态点 / 账号行 / 分隔线 | |

### 三个关键交互

**① 拖进容器**
把左栏组件拖到容器**虚线框附近**（有 12px 宽容）即可放进去。
拖拽过程中所有容器会高亮，告诉你哪里能放。

**② Tab 与面板联动**
拖一个「下划线 Tab」进来，编辑器会**自动创建对应数量的面板**。
点 Tab 时下面内容跟着换。

两个面板靠 `bind` 属性关联：
```
tabbar    bind="t1"        →  记录当前选中项
tabpanel  bind="t1" idx=0  →  仅当选中第 0 项时显示
tabpanel  bind="t1" idx=1  →  仅当选中第 1 项时显示
```

> `bind` 在拖入时自动设成该 tabbar 的 id，一般不用手改。
> 改了 tabbar 的 id 才需要跟着改。

**③ 选中与删除**
点元素选中（右栏改属性）。选中后右上角出现 `×`，点它删除。

## 导出

点右上角「导出给我」，复制 JSON 发我。

格式：
```json
{
  "cardTitle": "ZCode Bridge (GLM free)",
  "elements": [
    { "id": "e1", "kind": "row", "props": { "children": [ ... ] } }
  ]
}
```

## 已知限制

- **属性面板只覆盖主要字段**，不是所有 props 都能在界面上改
- **不能撤销**（没有历史栈）—— 改错了只能手改回去
- **不能保存/加载**工程文件，刷新页面会回到初始卡片
  —— 建议调好后立刻「导出给我」，别刷新
